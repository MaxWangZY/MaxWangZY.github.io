# NYT-Theme Redesign Plan

Revamp the site's visual design to a New York Times-inspired black-and-white newspaper aesthetic. **All content stays as-is** (posts, experience entries, artifacts data, CV, bio text) — only presentation changes. Per your choices: name as nameplate, Newsreader + Libre Franklin from Google Fonts, leaner front page (remove the two Experience/Blog link cards), portrait keeps color.

## Why this is low-risk

The site is a hand-rolled Jekyll site with no theme gem, no JS, and one stylesheet. The entire palette lives in the `:root` block of `assets/css/style.css`; header/footer live in `_layouts/default.html`. Only 3 files change.

## 1. `_layouts/default.html` — NYT masthead

Replace the current left-brand/right-nav header with a centered nameplate masthead:

- **Masthead**: centered `a.brand` reading "Zhengyang Wang" (Newsreader 700, ~clamp(2.2rem–3rem), tight letter-spacing, links to `/`), with "Optimization is everywhere." as a small italic serif line beneath it. A small date line above (generated via Liquid `site.time` — design chrome, not new content).
- **Nav bar below the masthead**: same five links (Home / Experience / Blog / CV / GitHub) with the existing active-state Liquid logic, restyled as a centered row of uppercase Libre Franklin labels. NYT-style rules: a strong black rule above the nav bar, hairline below it.
- **Fonts**: add Google Fonts `<link>` (with preconnect) for Newsreader (roman + italic, 400–700) and Libre Franklin (400–700), `display=swap`.
- Footer markup unchanged (CSS restyles it); body-class mechanism and CV link via `{{ '/assets/cv/Zhengyang_Wang_CV.pdf' | relative_url }}` preserved exactly.

## 2. `assets/css/style.css` — full re-skin (same class names, so content markup keeps working)

**New tokens** — white paper, black ink, gray hierarchy, zero accent color:

```
--bg / --paper: #ffffff    --text / --accent / --accent-strong: #121212
--muted: #5a5a5a   --soft: #8c8c8c   --line: #e2e2e2   --warm (hover): #666666
+ --font-serif: Newsreader, Georgia, "Times New Roman", serif
+ --font-sans: "Libre Franklin", system-ui, sans-serif
```

**Typography**: body becomes Newsreader serif (~1.05rem / 1.68); all UI/meta (nav, dates, kickers, footer, buttons) becomes uppercase letter-spaced Libre Franklin. Headings: serif 700 with slight negative tracking.

**Component restyles**:
- Links: black with underline, hover gray. Headline links: black, no underline, hover underlines (NYT behavior).
- `.artifact-type` kickers → gray Franklin uppercase (replacing teal).
- List rows (`.artifact` / `.post-row` / `.entry`): keep the 142px date-column grid; hairline separators; first row gets a heavier 2px black top rule (replacing teal) as the section opener.
- `.page-action` (View full CV button): square corners, 1px black border; hover inverts to black fill / white text.
- Portrait: square corners (no radius), thin hairline frame — keeps color.
- `.page-post h1`: centered serif headline, larger clamp; keep the measure-capped body and h2 hairline dividers.
- Section `h2`s ("Recent", "Research", "Projects", "Work"): bold serif with a short black rule treatment.
- Footer: thick-over-thin double rule on top, small uppercase Franklin.
- Remove all `border-radius` (6px buttons/images, 999px pills → square) and drop the now-unused `.link-grid` styles.
- Keep `color-scheme: light`, the 760px responsive breakpoint (updated for the stacked masthead/nav on mobile), and `prefers`-free simplicity — no JS added.

## 3. `index.md` — leaner front page

Delete only the final `.link-grid` section (the two Experience/Blog cards — nav already covers both). Hero + Recent list remain, byte-for-byte otherwise.

## Untouched

`experience.md`, `blog.md`, `_posts/*`, `_data/artifacts.yml`, `_config.yml`, `assets/images/portrait.jpg`, `assets/cv/Zhengyang_Wang_CV.pdf`, `Gemfile`.
